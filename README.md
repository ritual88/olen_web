# Сайт Ольги Кисуриной

Статический сайт на Astro. Шесть страниц, форма заявки уходит в Telegram.

## Как посмотреть

Двойной клик по файлу **`Смотреть сайт.cmd`** в этой папке.

Откроется чёрное окно и браузер с адресом `http://localhost:4321`. Окно нельзя закрывать, пока смотрите сайт — оно и есть сервер. Закрыли окно — сайт остановился.

Пока окно открыто, любые правки видны сразу после обновления страницы.

## Как править текст

**Вариант 1 — редактор.** Двойной клик по `public/tools/editor.html`. Откроется страница со всеми текстами сайта. Правите, нажимаете «Скачать content.json», присылаете файл — его подставляют в проект.

**Вариант 2 — руками.** Все тексты лежат в `public/content.json`. Правится в блокноте, структура простая. После сохранения страница обновится сама.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | локальный сервер с обновлением на лету |
| `npm run build` | собрать сайт в папку `dist` |
| `npm run preview` | посмотреть собранную версию |
| `npm start` | запустить сервер для хостинга (Timeweb) |
| `npm run editor` | открыть редактор текста |

## Структура

```
src/
  data/site.ts        ссылки на тексты из content.json
  layouts/Base.astro   <head>, метаданные, шапка, подвал
  components/          шапка, подвал
  pages/               страницы: /, /services, /about, /contact, /privacy, 404
  styles/              токены и стили
public/
  content.json         все тексты
  img/                 логотип, картинки, превью ссылки
  fonts/               шрифты
  js/                  скрипты формы, появления секций, Метрики
  tools/editor.html    редактор текста
server.mjs             сервер для Timeweb: статика + приём заявки
api/contact.js         логика заявки (используется и на Vercel)
Dockerfile             запасной вариант сборки в контейнере
```

## Чего нельзя делать

- Класть токены и пароли в код — только в `.env` (он не попадает в git) и в переменные хостинга.
- Удалять `.gitignore`: он держит `.env`, `node_modules` и `dist` вне репозитория.
- Менять заголовки безопасности без понимания: сайт может перестать работать.
